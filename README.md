# 냉파 (냉장고 파먹기)

등록은 10초, 확인은 한눈에, 기한은 놓치지 않게 해 주는 개인용 식재료 관리 모바일웹(PWA)입니다.

**바로 사용하기**: https://pibic98-won.github.io/ref/

## 주요 기능

- **빠른 등록**: 이름만 입력해도 저장되고, 구매일(오늘)과 보관 위치(마지막 선택값)는 자동으로 채워집니다. "저장 후 이어서"로 연속 등록할 수 있습니다.
- **한눈에 보기**: 냉장·냉동·상온 탭으로 나눠 보고, 기한 있는 재료는 임박한 순, 기한 없는 재료는 구입한 지 오래된 순으로 보여 줍니다.
- **기한·경과일 표시**: D-day(만료·오늘까지·임박·주의)와 "구입 N일째"를 색상과 글자로 함께 표시합니다.
- **스와이프 정리**: 카드를 오른쪽으로 밀면 소비, 왼쪽으로 밀면 폐기되며, 바로 되돌릴 수 있습니다.
- **먼저 먹을 식재료**: 만료·임박·오래된 재료를 모아 한 번에 소비 또는 폐기할 수 있습니다.
- **편의 기능**: 이전에 입력한 이름 자동완성(보관 위치까지 기억), 이름 검색, 다크 모드, 기준일 설정
- **백업**: 데이터를 JSON 파일로 내보내고 다시 가져올 수 있습니다.

## 홈 화면에 설치하기

- **안드로이드**: 크롬으로 접속한 뒤 ⋮ 메뉴에서 **앱 설치**(또는 홈 화면에 추가 → 설치)를 누릅니다.
- **아이폰**: 사파리로 접속한 뒤 공유 버튼에서 **홈 화면에 추가**를 누릅니다.

설치하면 주소창 없이 앱처럼 열리고, 인터넷 연결 없이도 사용할 수 있습니다.

## 데이터 안내

- 모든 데이터는 기기의 브라우저 저장소(IndexedDB)에만 저장되며, 외부로 전송되지 않습니다.
- 브라우저 데이터를 지우면 함께 삭제될 수 있으니 **설정 → 데이터 백업**으로 가끔 내보내 두세요.
- 기한 표시는 입력한 날짜를 기준으로 한 참고용입니다. 드시기 전에 냄새와 모양을 꼭 확인하세요.

## 개발

빌드 과정 없는 정적 파일입니다.

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면·스타일·동작 전체 |
| `sw.js` | 서비스 워커(오프라인 캐시) |
| `manifest.webmanifest` | 앱 이름·아이콘 등 설치 정보 |
| `icon-*.png`, `apple-touch-icon.png`, `icon.svg` | 앱 아이콘 |

로컬 실행:

```bash
python -m http.server 5173
```

`main` 브랜치에 push하면 GitHub Pages에 자동으로 배포됩니다.
